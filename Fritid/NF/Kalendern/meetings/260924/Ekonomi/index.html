Resultaträkning

Intäkter och kostnader sammanställda ur föreningens huvudbok, med cykelkartan och fotoutställningen visade som egna finansierade projekt.

Sidan kunde inte läsa in resultaträkningen. Det händer om filen öppnas direkt i Utforskaren (dubbelklick) – webbläsaren blockerar då datafilerna av säkerhetsskäl. Öppna sidan i stället via en lokal webbserver (t.ex. python -m http.server i den här mappen) eller via GitHub Pages när sidan är publicerad.

Sammanfattning: intäkter, kostnader och resultat#

Belopp (kr)

Per projekt, kostnad mot riktad intäkt:

    { } GitHub

    Hur den här sidan är byggd

    Två delar: tekniken i sidan, och metoden som faktiskt användes för att ta fram den. Inget påhittat, bara det som är sant.

    Tekniken

    Vanilla HTML/CSS/JS

    Ingen ramverk, inget byggsteg. Statiska filer som körs direkt på GitHub Pages.

    Data ligger i egna JSON-filer

    Varje resultaträkning är en egen fil i data/ (t.ex. 2026-09-23.json), listad i data/manifest.json. Sidan hämtar filerna med fetch och bygger om innehållet när du byter period i väljaren.

    Ingen data skickas någonstans

    Sidan pratar inte med någon server utöver att läsa sina egna JSON-filer, och skickar ingenting vidare.

    Radmarkeringen kodar projekt, inte tycke

    Cykelkartans och fotoutställningens rader får varsin färg för att markera att de hör ihop (kostnad + riktad intäkt) – samma två rader oavsett vilken period som visas.

    Samma hörn-mönster som Kalendern-sidan

    GitHub-länken och teknik-knappen (.corner, .modal-overlay) återanvänder mekaniken och den gröna paletten från Kalendern/index.html en nivå upp.

    Metoden

    Beloppen är avstämda mot huvudboken

    Varje delsumma i huvudboken (Huvudbok_260923.docx) är omräknad rad för rad innan den fördes in här, och sluttotalen stämmer mot periodens bokförda resultat.

    Förenklad efter en första, för ambitiös version

    Den första versionen hade separata statistikkort och stapeldiagram per projekt. Kent bad om att gå tillbaka till en enda tabell, liknande hans egen bifogade sammanfattning.

    Byggd för att uppdateras, inte skrivas om

    Sidan är förberedd för att en ny resultaträkning bara lägger till en ny datafil, så tidigare perioder går att växla tillbaka till.

    Byggd lokalt, inte publicerad ännu

    Sidan skapades och testades i webbläsarförhandsvisning; commit och push till GitHub sker bara när Kent ber om det.
